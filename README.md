## Описание

Приложение показывает последовательность подсвечивающихся ячеек, которую пользователь должен повторить. После каждой успешной попытки длина последовательности увеличивается на 1. Игра заканчивается при первой ошибке.

## Технологии

- **TypeScript** — строгая типизация
- **React 18** — компонентный UI
- **Vite** — сборщик проекта
- **CSS** — стилизация (без сторонних UI-библиотек)
- **localStorage** — хранение рекорда и истории
- **Jest + ts-jest** — юнит-тестирование

## Структура проекта

```
sequence-game/
├── index.html
├── package.json
├── tsconfig.json
├── vite.config.ts
├── jest.config.js

    ├── main.tsx          — точка входа
    ├── App.tsx           — главный компонент
    ├── styles.css        — стили
    ├── components/
    │   └── GameBoard.tsx — компонент игрового поля
```

## Запуск

```bash
npm install
npm run dev        # dev-сервер
npm run build      # сборка
npm test           # тесты
```

## Функциональность

- Запуск новой игры
- Генерация случайной последовательности
- Поэтапное увеличение сложности
- Визуальная обратная связь (верно/неверно)
- Индикатор прогресса внутри уровня
- Сохранение рекорда (localStorage)
- История попыток с отметкой лучшего результата
- Экран завершения с итогами
- Адаптивный интерфейс
