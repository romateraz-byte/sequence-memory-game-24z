## 🎮 О приложении

Игра генерирует случайную последовательность подсвечивающихся ячеек на поле 3×3. Задача игрока — повторить её в точном порядке. После каждого верного ответа длина последовательности увеличивается на 1. Игра завершается при первой ошибке.

Приложение разработано в рамках курсовой работы по дисциплине **«Объектно-ориентированное программирование»**.

## ✨ Функциональность

- 🟦 Игровое поле 3×3 из 9 ячеек
- ⚡ Генерация случайной последовательности с нарастающей сложностью
- 💡 Подсветка ячеек при показе и при вводе (верно / ошибка)
- 📍 Индикатор прогресса внутри текущего уровня
- 🏆 Сохранение рекорда между сессиями (localStorage)
- 📋 История всех сыгранных партий
- 🖥️ Экран завершения с итоговым счётом
- 📱 Адаптивный интерфейс (desktop + mobile)

## 🚀 Быстрый старт

### Вариант 1 — без установки (рекомендуется)

Скачайте файл `index.html` и откройте его двойным кликом в браузере. Никаких зависимостей не требуется.

### Вариант 2 — с Vite (dev-режим)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ВАШ_НИК/sequence-memory-game.git
cd sequence-memory-game

# 2. Установить зависимости
npm install

# 3. Запустить dev-сервер
npm run dev
```

Приложение откроется на `http://localhost:5173`

### Доступные команды

```bash
npm run dev      # Запуск dev-сервера
npm run build    # Сборка в папку dist/
npm run preview  # Предпросмотр сборки
npm test         # Запуск unit-тестов
```

## 🧪 Тестирование

Unit-тесты написаны с использованием **Jest** и **ts-jest**. Покрывают:

- Генерацию случайных ячеек (диапазон значений)
- Расширение последовательности (`generateSequence`)
- Проверку ввода пользователя (`checkInput`)
- Константы (`SIZE === 9`)

```bash
npm test
```

## 🎯 Как играть

1. Нажмите **«Старт»**
2. Запомните, какая ячейка подсветилась
3. Нажмите на неё в том же порядке
4. С каждым уровнем последовательность становится длиннее на 1
5. Ошиблись — игра завершается, результат сохраняется в историю
